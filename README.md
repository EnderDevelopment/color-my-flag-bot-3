# ColorMyFlagBot

ColorMyFlagBot is a Discord bot designed to enhance the "Color My Flag" game experience. It provides a user-friendly interface with functional buttons and an automatic coloring feature, making it easier for players to interact with the game. Keywords: Discord bot, game enhancement, automatic coloring, user interface.

## Install

1. **Invite the Bot to Your Server:**
   - Go to the [ColorMyFlagBot invite page](https://discord.com/api/oauth2/authorize?client_id=YOUR_CLIENT_ID&permissions=8&scope=bot).
   - Select the server you want to add the bot to and authorize the bot.

2. **Set Up the Bot:**
   - Ensure the bot has the necessary permissions to send messages and interact with users.

## Use

1. **Start the Game:**
   - Type `!colorflag` in any channel where the bot has access to start the game.

2. **Use the Buttons:**
   - The bot will provide interactive buttons to color the flag manually or automatically.

3. **Color the Flag:**
   - Click the "Color Flag" button to manually color the flag.
   - Click the "Auto Color Flag" button to let the bot automatically color the flag for you.
